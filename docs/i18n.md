# Languages

The site has Czech (`cs`, default) and English (`en`).

## URLs

Every language has its own prefix: `/cs/…`, `/en/…`. Slugs are English in
every language (`/cs/guide/connections/`), so the language switch only
changes the prefix. The root `/` is a small page that sends the browser to
the first language it prefers, or to Czech.

## Where texts are

| Kind | Place |
|---|---|
| Short UI texts | `src/i18n/ui.ts`, one object per language |
| Guide | `src/content/guide/<lang>/<slug>.md` |
| Legal pages | `src/content/legal/<lang>/<slug>.md` |
| License table | `src/data/licenses.ts`, field `use` per language |

`ui.ts` types every language as `Record<UiKey, string>`, so `npm run check`
fails when a language misses a key.

## Add a language

1. Add the code to `src/i18n/locales.mjs` and to the `Locale` type and
   `localeNames` in `src/i18n/ui.ts`.
2. Add its object of UI texts in `src/i18n/ui.ts`.
3. Copy `src/content/guide/en/` and `src/content/legal/en/` to the new code
   and translate them.
4. Add the `use` text in `src/data/licenses.ts`.
5. Add `og:locale` in `src/layouts/Base.astro`.
6. `npm run check && npm run build`.
